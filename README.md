Losovač je jednoduchá WinForms aplikace vytvořená jako moje první okenní aplikace. Vytvořená je ve WinForms. Umožňuje zadat seznam soutěžících, zvolit počet výherců a následně náhodně vylosovat zadaný počet jmen. Výsledky se přehledně zobrazí v okně aplikace. Losování má punc dramatičnosti tím, že po dobu dvou sekund běží animace v progress baru a tlačítko Losovat je po tuto dobu nefunkční. Po uplynutí této doby se objeví v boxu Výherci jména výherců. Doplněná knihovna pro opravu (korekci) vstupů zadaných uživatelem. Konkrétně v případě chybně zadaného jména (malé počáteční písmeno) aplikace sama toto opraví na velké počáteční písmeno dle gramatické správnosti.
